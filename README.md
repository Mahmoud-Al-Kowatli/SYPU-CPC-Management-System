# SYPU-CPC Management System

**Software Engineering 1 Project - Summer Semester 2025/2026**[cite: 1]  
**Al-Sham Private University (ASPU) - Faculty of Engineering, ITE**[cite: 1]

## 📌 Project Overview
This project is a comprehensive software engineering practice aimed at building a management system for the Syrian Private Universities Collegiate Programming Contest (SYPU-CPC)[cite: 1]. The system facilitates coordination among the Contest Manager, Technical Team, Organizing Team, and Media Team[cite: 1].

## 📁 Repository Structure

The repository is structured based on the official project requirements[cite: 1]:

* **`01-Requirements_and_SRS/`**[cite: 1]
  Contains the functional and non-functional requirements, along with the final comprehensive Software Requirements Specification (SRS) document based on the IEEE standard[cite: 1].

* **`02-UML_Modeling/`**[cite: 1]
  Includes all required UML models (No AI tools used in generation)[cite: 1]:
  * Use Case Diagram and Narratives[cite: 1].
  * Activity Diagrams[cite: 1].
  * System Sequence Diagrams (SSD)[cite: 1].

* **`03-UI_Prototype/`**[cite: 1]
  Contains screenshots and screen recordings of the initial User Interface prototype[cite: 1].

* **`04-Jira_Agile/`**[cite: 1]
  Contains Agile project management artifacts, including User Stories (at least 5), Product Backlog setup, Sprint 1 tasks, and Jira board screenshots[cite: 1].

* **`05-Integration_Config/`**[cite: 1]
  Includes proposed ready-made tools and services (Stand-alone, Component, Web Service) suitable for integration into the system[cite: 1].
